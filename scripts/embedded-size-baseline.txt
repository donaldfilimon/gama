# Embedded artifact size pin.
#
# ADR 0009 cites "the Embedded size gate not regressing" as the evidence for
# its zero-runtime-cost claim, and ADR 0011 records the per-host identity
# store's +47,276 bytes as a deliberate cost. Until 2026-09-06 no such gate
# existed: check-embedded.sh computed the byte count, printed it, and asserted
# nothing at all, so an artifact could double and the gate still said OK.
#
# The count is specific to one compiler and one source tree. This pin names the
# compiler revision check-embedded.sh already requires unconditionally, so a
# snapshot bump fails here first and forces a deliberate re-measure rather than
# a silently rebased number.
#
# The tolerance is two-sided on purpose. An artifact that grows past it is the
# regression ADR 0009 cares about; one that shrinks past it is either a real
# win worth recording or a sign the link produced something other than the
# whole module, and both deserve a human deciding rather than a stale baseline
# quietly absorbing them.
#
# Re-measured 2026-09-22 at the same compiler revision. check-embedded.sh
# compiles GamaCore alone, and c7e21cb added the action-identity tables there
# (ActionID, the host action maps, and the view modifier). The linked artifact
# is 679112 bytes, 37648 above the 2026-09-06 pin of 641464, which is outside
# the previous 2% band. Capability detection and the C restore buffer are not
# in this compile.
#
# Re-measured 2026-09-23 at the same compiler revision, native-presentation
# Task 1 (LayoutMetrics and metrics-driven layout). New:
# Sources/GamaCore/LayoutMetrics.swift (a public struct of four escaping
# closure properties plus `.cell`); Layout.swift now threads a LayoutMetrics
# value through measure/layout/measureStack/flexMinimum/layoutStack instead
# of hardcoding cell arithmetic, and the public measure(_:proposal:) /
# layout(_:in:) entry points now forward into metrics-taking overloads. The
# linked artifact is 781964 bytes, 102852 above the 679112 pin above, well
# outside the 2% band — expected for a change whose entire point is a new
# public closure-bearing type plus rewriting every arithmetic site in the
# layout solver to call through it; Embedded Swift's whole-module compile
# keeps the escaping-closure call sites and the forwarding overloads
# distinct rather than folding them away. No `RenderNode` case, MLIR op, or
# DrawList wire changed, and `.cell` layout stays byte-identical (see
# LayoutTests/P1LayoutTests/DrawListTests/LayoutMetricsParityTests).
#
# Grammar is deliberately tiny: blank lines, `#` comments, and key = "value".
# Anything else fails the read, for the same reason scripts/lib/manifest.sh is
# strict — this is a pin, not a configuration language.
revision = "95c5142e84b82c1"
bytes = "781964"
tolerance_percent = "2"
