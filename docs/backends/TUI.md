# Terminal and plain output

Interactive TUI targets macOS and Linux through installed std APIs. Windows retains plain/headless output. Adaptive selection is based on stdout; --gama-plain and --gama-tui are explicit overrides, with the last recognized override taking precedence. Inputless plain mode ends at the first clean/quiescent frame. Completion is explicit application status; the caller owns process exit policy. Semantic lines are acknowledged only after successful delivery. Applications can call `complete` and `emit` from live action, key and lifecycle callbacks under the [outcome admission rules](../StateAndIdentity.md). Plain presentation uses queued semantic lines in place of painted text; ANSI presentation retains the visual frame. For a completion observed during a normal run-loop iteration, the loop delivers any dirty frame before capturing the completion result. Reserved quit can exit without another frame. The `will_terminate` callback runs after the run result has been captured; outcomes or lines submitted there do not trigger another flush or replace that result. `runAdaptive` writes its optional completion message to stderr and returns the status to the caller.

Terminal acquisition owns raw settings, managed signal dispositions and output flags. Each acquisition consumes a unique, never-recycled epoch slot (256 per process). Darwin readback omits SA_RESETHAND, so pre-existing custom handlers require caller-owned exact installation records through acquireWithActions/Surface.dispositions. Observable fields are validated, hidden bits remain the caller truth contract. Default/ignored actions use normal capture. Unknown custom capture is intentionally unsupported.

Restoration uses TCSANOW and no output in signal handlers. Structured teardown restores settings before best-effort nonblocking presentation cleanup; output stalls fail after a bounded interval. Signal forwarding preserves displaced semantics. External process exit, SIGKILL, concurrent disposition mutation and unreachable descriptors after true peer hangup are outside unconditional restoration guarantees. Host PTY proof and supporting Apple source inference are distinct; the cited XNU source is not the exact beta-kernel source.

Drawing prepares all bytes before transport. Failure preserves internal host/raster publication, but partial external writes cannot be rolled back. [Capabilities](../Capabilities.md) records runtime qualification and unavailable-host gaps.
