# Troubleshooting

A missing Zig, Python, Node, tmux or mlir-opt is a failed prerequisite, not a skipped pass. Set `GAMA_MLIR_OPT` for the script or `-Dmlir-opt=` for the build graph if the existing parser is outside PATH.

Interactive terminal acquisition fails before mutation when Darwin custom managed dispositions lack exact caller installation records. Use the explicit Surface dispositions API when embedding around such handlers; do not reset arbitrary application handlers to conceal the failure. A terminal lease exhausts after 256 process acquisitions by design.

For a stuck interactive demo, the owned driver quit command checks the receipt/token before cleanup. Existing names are rejected on launch. For output stalls, the runtime returns a bounded error and structured teardown restores terminal state. External exit, SIGKILL and uncatchable failures are outside that guarantee.

On ENOSPC, stop owned builds and inspect only confirmed disposable generated output with current holders. Preserve review archives, private history, runner data and other worktrees. Never use broad git clean or delete a retired parent containing protected cache/configuration data.
